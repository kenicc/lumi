# LUMI Pocket

Kieszonkowe urządzenie dla seniora i osoby z niepełnosprawnością: rozmowy przez kartę SIM (VoLTE), radio FM i internetowe, muzyka od rodziny, zegar i pogoda. Rodzina ustawia wszystko zdalnie, użytkownik niczego nie konfiguruje.

- [`firmware/`](firmware/) - oprogramowanie prototypu na ESP32-S3 (PlatformIO, LVGL 9)
